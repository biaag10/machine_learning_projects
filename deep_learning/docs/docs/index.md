# Deep Learning

## Descrição

Projeto de Deep Learning da disciplina de Machine Learning (SENAI CIMATEC): fundamentos de
redes neurais com TensorFlow e Keras e classificação de imagens do CIFAR-10 com uma CNN.

## Comandos

O `Makefile` concentra os comandos principais:

- `make requirements`: instala as dependências com uv;
- `make data`: baixa a base CIFAR-10;
- `make train`: treina e avalia a CNN;
- `make test`: roda os testes.
