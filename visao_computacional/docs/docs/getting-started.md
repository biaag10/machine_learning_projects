Primeiros passos
================

1. Instale o [uv](https://docs.astral.sh/uv/) e rode `uv sync` na pasta `visao_computacional/`.
2. Coloque as imagens e bases originais em `data/raw/` (essa pasta não vai para o Git).
3. Abra os notebooks da pasta `notebooks/` com o kernel do ambiente do projeto.
4. Rode os testes:

    ```bash
    uv run pytest tests
    ```
