# Visão Computacional

## Descrição

Projeto de Visão Computacional da disciplina de Machine Learning (SENAI CIMATEC): fundamentos
de imagens digitais e classificação de imagens com Redes Neurais Convolucionais (CNN).

## Comandos

O `Makefile` concentra os comandos principais:

- `make requirements`: instala as dependências com uv;
- `make test`: roda os testes.
